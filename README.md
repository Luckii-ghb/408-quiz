# ⚡ 408 计算机考研闯关工作台

一个**单文件、离线可用**的 408 考研刷题 / 背诵工作台。下载 `index.html`，双击用浏览器打开即可使用，无需安装任何依赖。

## ✨ 功能

### 学习
- **闯关地图**：章节 → 关卡逐级推进，70% / 85% / 100% 三星判分
- **知识点卡片**：每张卡配「定义 / 考法 / 前因后果 / 逻辑链 / 口诀」五段式讲解 + 教材配图
- **交互动画**：TCP 三次握手、拥塞控制、GBN 滑动窗口、ARP 解析、CSMA/CD、IP 分片
- **苏格拉底式串讲**：每关学完自动出 2 问检测，答错先给提示，讲完飘出小标题

### 刷题
- 四选一 + 解析 + 考点卡联动，错题自动进**错题本**
- 错题本支持「查阅知识卡片」聚合视图
- 上一题 / 下一题导航，做题进度自动落盘（换页不丢）

### 背诵
- **每日背诵**：47 组知识点卡片 / 131 个挖空检测点
- **每日打卡**：勾选今天学完的章节，次日自动排入对应复习
- **艾宾浩斯曲线**：答对进阶、答错回炉，按记忆节奏安排到期卡片
- 答错会显示所选错误选项的**正确含义辨析**（如「数据项 vs 数据元素」）

### 工具
- **手写批注**：多图层画笔 / 橡皮 / 80 步撤销 / 双指点击撤销上一笔 / 全站图层
- 面板 ✕ = 收起（手写继续生效）、⏻ = 关闭
- 知识点收藏星号、荧光笔标记

### 进度与同步
- 进度存 `localStorage`，刷新 / 关闭不丢
- 内置可选**云同步**（邮箱登录），跨设备合并策略：星级取 max、已看取并集、做题进度取较新

## 🚀 使用方式

### 方式一：本地打开（推荐）
1. 下载本仓库的 `index.html`（约 10 MB）
2. 双击用 Chrome / Edge / Safari 打开即可

### 方式二：GitHub Pages 在线访问
1. Fork 或使用本仓库
2. `Settings → Pages → Branch: main / (root) → Save`
3. 访问 `https://<你的用户名>.github.io/<仓库名>/`

> 云同步功能依赖作者部署的后端；fork 后本地打开 / 自建部署时，其余功能全部可用，登录同步按钮会提示不可用，不影响做题。
